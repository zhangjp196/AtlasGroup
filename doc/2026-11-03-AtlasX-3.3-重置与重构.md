# AtlasX 3.3 · 旧界面 / 旧数据退场，重构起点

> 状态：**进行中**（2026-11-03）
> 版本：3.3.0（内部数据库结构版本 4，用于和旧库断代）

## 1. 这次做了什么

### 旧界面退场

- `/classic` 不再提供旧界面：返回 **410 Gone**。
- 新界面 `/` 是唯一入口；设置、模型订阅、工作区、角色、群组都在新壳里。
- 旧前端文件暂时还留在仓库里供测试引用，但运行时不暴露；下一阶段直接移出 `web/`。

### 旧数据退场

- 数据库结构版本升到 **4**（内部断代标记）。
- 启动时如果发现旧库（schema < 4）：
  1. 把整个库文件改名为 `agent_zero.db.legacy-<时间戳>.bak`（含 `-wal` / `-shm`）；
  2. 按新结构新建空库；
  3. **不迁移**旧会话 / 角色 / 群组 / 设置。
- 旧库仍保留在数据目录，可手动拷走；应用不再读取它。
- LLM 的 `config.yaml` / Keychain 不属于数据库，不受这次重置影响。

### 工作区增改

- 工作区画布：`＋ 添加`（名称 + 绝对路径）、`重命名`、`上一级`、`打开文件夹`。
- 工作区列表右键：在画布打开 / 绑定到当前窗口 / Finder 打开 / 复制路径 / 重命名 / 归档 / 删除（归档）。
- 删除只是从列表隐藏，目录、会话、文件保留。

### 交互：角色点击直接单聊 + 右键菜单

- 角色列表 / 角色卡片**单击 = 打开单聊**；已有该角色的单聊则复用。
- 右键菜单覆盖：
  - 角色：单聊 / 新建单聊 / 编辑 / 查看详情 / 复制角色 / 存为持久 / 加入群组 / 复制 ID / 删除；
  - 会话：打开 / 标记已读 / 重命名 / 绑定工作区 / 复制 ID / 删除；
  - 群组：打开群聊 / 编辑 / 复制群组 / 复制 ID / 删除；
  - 工作区：在画布打开 / 绑定到当前窗口 / Finder 打开 / 复制路径 / 归档；
  - 窗口标题：最小化 / 最大化 / 平铺 / 复制会话 ID / 关闭；
  - 消息：复制文本 / 复制为引用 / 复制消息 ID。

### 按钮修复（真实 bug）

- `modal()` 每次重写 footer 时把 `#modalCancel` 删掉了，随后又对 null 设置 `onclick`：
  任何「新建会话 / 新建角色 / 新建群组 / 编辑群组」的弹窗都会抛异常，取消和保存全部失效。
  现在取消按钮重建时保留 id，弹窗 Promise 能正常结束。
- 工作区「打开文件夹」：接 `/workspace/reveal`，在 Finder 中打开根目录。
- 群组编辑：新增「删除群组」，删除后绑定会话退回单聊。
- 悬浮窗：新增「最大化」按钮（与平铺 / 最小化共存）。
