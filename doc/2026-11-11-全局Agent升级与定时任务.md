# 全局 Agent 升级、会话多角色与定时 / 自由触发（3.12.0）

## 1. 全局入口拆成两个

左轨底部现在是两个独立入口：

| 入口 | zone | 职责 |
| --- | --- | --- |
| 全局管理 | `global-agent` | 跨会话审批、待回答、未读、运行状态、角色在线状态、部门 / 角色库、定时任务管理 |
| 全局对话 | `global-chat` | 和普通会话一样聊天；可以添加任意参与角色、调用角色讨论、派遣后台任务 |

两者各自只有一条常驻会话，互不混用历史；全局管理会话不参与普通会话的 2 个悬浮窗上限。

- 后端：`POST /app/global-agent` / `POST /app/global-chat`
- 管理入口只下发管理工具（`app_manage` / `role_manage` / `department_manage` / `schedule_manage` 等），不继承 shell / 文件能力。

## 2. 角色在线状态

状态存在角色 `envelope.status`（`online` / `offline`），默认在线：

- 右侧「在线角色」只显示在线角色，点击打开（或新建）单聊会话；右键可打开聊天 / 设为离线。
- 角色页卡片显示在线 / 离线，右键菜单可切换。
- 全局管理 Agent 通过 `role_manage(status="online"|"offline")` 管理。
- 状态与角色能力包络分开保存：切换工具 / 工作区不会重置在线状态。

## 3. 群组功能移除

群组不再是一个需要创建、维护、绑定的实体。所有会话统一为：

```
主持角色 (conversations.role_id)
  + 参与角色 (conversation 私有 participants-* 团队)
  + 临时角色 (roles.scope=temporary, session_id=当前会话)
```

- 新建会话：选择主持角色 + 可选参与角色（最多 12 个）。
- 聊天头部「参与角色」：随时增删参与角色、新建 / 删除 / 转正临时角色。
- `PUT /conversations/{id}/participants` 只改当前会话；旧公共团队不再被修改。
- 旧 `/group` 路由已删除；`/teams` 接口保留为内部兼容层（私有参与团队仍复用该表）。
- 会话头像 / 标题 / 工作区跟随主持角色，不再跟随群组。

## 4. 悬浮窗与在线角色栏

- 普通会话悬浮窗最多 2 个（不含全局管理 / 全局对话）；会话列表点击后进入悬浮窗。
- 右侧在线角色栏模仿 IM 联系人：点击直接聊天，右键快捷操作。
- 聊天窗口仍可拖动、聚焦置顶；全局管理窗口位置记忆在本地。

## 5. 定时任务 + 自由触发

新增 `scheduled_tasks` 表与 `schedule_service`，后台 ticker 每 20 秒检查一次到期任务。

### 触发方式

| trigger_mode | 行为 |
| --- | --- |
| `scheduled` | 按 `schedule_kind` 固定触发：`once` / `interval` / `daily` / `weekly` |
| `smart` | 到达评估时间后，模型结合 `condition` 与上次结果判断是否执行（自由触发）；不触发则继续等待下一次评估 |
| `manual` | 只手动运行 |

`smart` 的 `schedule.every_minutes` 是**评估间隔**（最短 5 分钟），不是执行时刻。评估使用当前默认模型，超时 30 秒；失败保守地不触发。

### 执行

- 首次运行创建独立会话（标题 `定时 · 标题`），后续默认复用，可回看历史、继续追问。
- 任务可指定角色 / 工作区 / `run_mode`（`chat` / `autonomous`）与 `max_runs`。
- 运行完成由 ticker 同步 `last_status` / `last_result`，供 UI 与下一次自由触发判断使用。
- 全局管理 Agent 通过 `schedule_manage` 工具创建、修改、运行、暂停任务。

### API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET/POST | `/schedules` | 列表 / 新建 |
| GET/PATCH/DELETE | `/schedules/{id}` | 详情 / 修改 / 删除 |
| POST | `/schedules/{id}/run` | 立即运行 |
| POST | `/schedules/{id}/pause` | `{"paused": true/false}` |
| POST | `/schedules/{id}/evaluate` | 手动跑一次自由触发评估 |

## 6. 模型思考强度

模型档案的 `thinking_levels` 是字符串数组；设置页选择器支持 `allow-create`，可以输入并新增多个自定义档位（例如 `minimal` / `low` / `medium` / `high` / `xhigh` / 自定义名称），保存后出现在聊天输入框的思考强度下拉里。

## 7. 3.13.0 交互调整

- **会话延迟创建**：右侧角色 / 新建会话都先开草稿窗口；发出第一条消息时才 `POST /conversations`，空会话不再落库。
- **侧栏**：右侧改为「会话 / 角色」双栏，默认会话；宽度从 160px 提升到 480px（窄屏自适应），会话显示角色、最后消息、未读、运行中，角色显示岗位、专长、模型与会话数。
- **窗口替换**：普通会话浮窗最多 2 个；打开第 3 个时自动替换最早打开的窗口，不再弹「请先关闭」。
- **移除可选默认项**：新建 / 会话管理 / 工单 / 定时任务不再提供「通用助手」角色选项；聊天模型选择显示「跟随角色模型」，系统模型仅作为后台兜底。
- **未读**：当前已打开的会话由前端自动标记已读，不弹新消息提示；关闭窗口后才重新计入未读。
- **关闭按钮**：会话头部移除临时角色 `＋` 与删除按钮，关闭 `×` 固定在最右侧；删除 / 清空 / 管理移到头像右键菜单。
- **头像右键**：会话管理、参与角色、重命名、复制 ID、清空上下文、标记已读、删除会话、关闭窗口。
- **主动消息**：普通角色可在会话中调用 `proactive_send` 安排一条延迟主动消息；不写用户气泡，到点后由模型生成 assistant 回复。全局 Agent 通过 `app_manage` 的 `proactive_status` / `set_proactive` / `cancel_proactive` 查看、限频、关闭或取消。

## 8. 3.14.0 样式与交互

- **会话浮窗可拉伸**：右缘 / 底缘 / 右下角三处可拖拽；尺寸记忆在 `localStorage`（`atlasx.chat.size.v3`）。
- **弹框 / 抽屉可拉伸**：`SideDrawer` 左缘手柄，拖拽宽度范围 340px ~ 94vw；关闭后回到组件默认宽度。
- **右侧栏**：
  - 左缘手柄可拖拽 320 ~ 720px；
  - 顶部按钮可一键收起为 64px 图标栏（会话未读会挂到头像上）；
  - 状态（宽度 / 是否收起）记忆在 `localStorage`（`atlasx.dock.v1`）。
- **点击不跳页**：右侧栏点会话 / 角色只打开或聚焦浮窗，不再切换主页面。
- **样式细节**：按钮 / 输入框 / 弹框 / 抽屉 / 浮窗统一圆角、阴影、聚焦态；关闭按钮悬停变红；发送框聚焦有 ring。
