# AtlasX 3.3 · 嵌入式会话、单聊归位、目录选择与对话对齐 V2

> 状态：**已落地**（2026-11-03）
> 范围：`web/v3`（唯一前端入口）+ 单聊路由 + 工作区添加
> 对应版本：3.3.7

## 1. 会话：嵌入式 + 会话列表切换（对齐 V2）

- 主画布就是会话容器：点左侧会话行直接打开 / 切回，不弹悬浮窗；
  顶部不再放标签条，避免和会话列表重复。
- 切换方式：
  - 会话列表点击；
  - `⌘/Ctrl + 1–9` 直达，`⌘/Ctrl + ←/→` 前后切换；
  - 后台会话收到新内容时，列表行点亮未读点；运行中显示运行点。
- 会话顶栏参考 V2：
  - 标题 + 副标题（群聊 / 单聊 · 角色 / 模式）；
  - 工作区 chip；
  - 运行中状态；
  - 会话信息、更多操作、删除会话、关闭会话；
  - 「更多」里是重命名、绑定工作区、标记已读、复制 ID、定位、删除、关闭。
- 会话列表顶部补齐刷新和新建；会话数量与打开数量仍在底部。
- 画布上的「新建会话 / 新建角色 / 新建群组」按钮补上了事件绑定（此前只绑了列表内按钮）。

## 2. 单聊不再变成「默认群聊」

三层修复：

1. `team_for_conv`：绑定团队但团队没有成员时按单聊处理。
2. 对话回复路由：不再从 `workspaces.host_role_id / member_role_ids` 惰性归一出默认团队；
   只有会话显式绑定、且有成员的团队才走群聊。
3. 启动清理：`team-default-*` 旧自动团队（即使有成员）全部解绑并删除；
   `GET /teams` 不再自动创建默认群聊。

结果：一个角色的单聊走单一角色回复，没有群名单、`@成员`、主持口吻或「已加入群聊」系统消息；
单聊复用同一会话（角色右键仍可「新建单聊会话」）。

## 3. 工作区新增：目录选择器对齐 V2

- 「＋ 添加」打开目录选择器，不再要求手填路径：
  - 绝对路径输入 +「前往」；回车即跳转；
  - 上一级 / 主目录；桌面端显示系统文件夹选择（`pick_folder`）；
  - 子文件夹列表、隐藏目录后置、当前目录筛选；
  - 最近使用路径记忆；记住的路径失效时自动回主目录；
  - 顶部名称默认取文件夹名，可修改；「使用此文件夹」添加并恢复已归档的同目录工作区。
- 工作区仍然只是文件 / 终端上下文容器，不承载聊天或角色。

## 4. 对话界面：对齐 V2 的过程时间线

- **深度思考**：流式 `thinking` 实时累加显示；一轮结束后自动折叠。
- **历史回放**：读取后端落库的 `reasoning` / `trace`，按“思考 → 工具 → 中间正文 → 最终答复”还原。
- **过程折叠**：一轮完成后，思考 / 工具 / 中间正文收进「过程」栏（默认收起），
  摘要显示「深度思考 N · 工具 N · 耗时」；最终答复留在外面。
- **工具行**：名称 / 耗时 / 成功或失败状态；参数或 diff 可展开。
- **自动向下**：默认贴底滚动；用户上滑后停止跟随，并出现「回到底部」按钮；
  切回会话时若原本在底部，自动回到底部。
- **输入框**：随内容自动增高（最高 180px），Send 后重置并保持焦点。
- Markdown 补上有序列表、引用、链接与列表样式；助手正文改为 V2 式的无气泡排版。

## 7. 全局 Agent（右下角机器人）

- 固定悬浮在右下角，聊天打开时上移到输入框上方。
- 两个数字角标：
  - 红色：待授权数（工具审批 + 待回答问题）；
  - 蓝色：未读会话数。
- 点击不是打开管理面板，而是打开一个**真正的全局 Agent 悬浮窗**
  （与普通会话同一套聊天 / 思考 / 工具界面，但固定在右下角、可拖动、可关闭）：
  - 会话 `zone=global-agent`，标题「全局 Agent」，不出现在普通会话列表；
  - 悬浮窗打开时隐藏右下角机器人，关闭后机器人重新出现；
  - 后端为它注入专属系统提示与 `app_manage` 工具；
  - 只下发管理类工具（app_manage / ask_user / role_manage / team_manage），
    不继承默认角色的 shell / 文件能力。
- `app_manage` 支持：
  - 查看跨会话待授权 / 未读 / 运行 / 会话授权快照；
  - 处理工具审批（允许一次 / 本会话 / 始终 / 拒绝）；
  - 回答其它会话的问题；
  - 标记会话已读（单个 / 全部）；
  - 设置会话权限或全局默认权限；
  - 停止运行中的 run。
- 全局 Agent 会话顶栏额外提供「系统通知」按钮；「更多」里可开启低风险代处理。
- 系统通知：浏览器授权后，待授权增加时发系统通知，点击通知直接打开全局 Agent。
- 代处理默认关闭；开启后只自动放行 **低风险** 工具，中 / 高风险仍等人确认。
- 数据接口：`GET /api/agent-zero/app/attention` 汇总跨会话审批 / 问题 / 未读 / 运行 / 会话授权策略；
  `app_manage` 与界面共用 `attention_service`，口径一致。
