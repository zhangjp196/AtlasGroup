# AtlasX V3 界面线框：主壳 + 悬浮会话

> 静态线框，只用于确认**信息架构与交互**，不是最终视觉。
> 打开方式：浏览器直接打开 [`index.html`](index.html)（无依赖、离线可用）。
> 左侧四个分区可切换；悬浮窗可拖动 / 缩放 / 最小化；右侧标注面板可关闭。

## 1. 目标与三条原则

1. **工作区就是工作区**：只负责文件、终端、项目上下文，不承载聊天，也不拥有角色。
2. **角色就是角色**：独立人格库；可持久、可临时；LLM 可在对话中直接创建。
3. **群组就是群组**：一组角色 + 协作方式；**不绑定工作区**，工作区只在「会话」层面可选绑定。

对话区 = **应用内多悬浮窗**：主界面不常驻聊天栏，聊天以可拖动、可缩放、可最小化的窗口浮在桌面上。

## 2. 信息架构

```
主壳
├─ 左轨（只有四个空间 + 设置）
│   ├─ 会话：找会话 / 打开悬浮窗（列表本身不聊天）
│   ├─ 工作区：文件夹、文件树、只读预览、终端
│   ├─ 角色：角色库（持久 / LLM 创建 / 临时）
│   └─ 群组：群组列表 + 群资料编辑
├─ 画布（随左轨切换）
│   ├─ 会话 → 工作区桌面（最近文件、打开的窗口、临时角色）
│   ├─ 工作区 → 文件树 + 预览
│   ├─ 角色 → 角色卡片网格
│   └─ 群组 → 群资料（成员 / 协作方式 / 会话与工作区绑定）
└─ 悬浮窗层（多开）
    ├─ 群聊窗口：群名 / 成员 / 绑定工作区 chip / 任务卡片 / 工具行 / 系统消息
    ├─ 单聊窗口：角色名 / 可选工作区 / 同一套消息与工具卡片
    └─ 最小化 dock：窗口缩成底部 chip，随时恢复
```

**移除**：右侧常驻 dock、顶栏一排图标、独立的「会话信息」抽屉（并入悬浮窗菜单）。

## 3. 悬浮窗交互

| 交互 | 规则 |
| --- | --- |
| 打开 | 点会话列表 / 角色 / 群组 → 打开对应悬浮窗；已打开则置顶 |
| 多开 | 可同时开多个（群聊、单聊混排）；建议上限 8 个，超出时提示 |
| 拖动 | 标题栏拖动；边界内收，不能拖出视口 |
| 缩放 | 右下角手柄；最小 380×300 |
| 最小化 | 收到左下角 dock chip；点 chip 恢复 |
| 层级 | 点击任意位置置顶；新打开的窗口在最上 |
| 记忆 | 位置 / 大小 / 打开的窗口按浏览器本地偏好保存 |
| 标题栏 | 群名/角色名、成员数、**绑定工作区 chip（会话级，可解绑）**、最小化 / 最大化 / 关闭、`⋯`（群资料 / 成员 / 临时角色） |
| 输入区 | `@` 补全群成员、`/` 命令、附件、发送；下方 chip 显示绑定工作区、协作方式、临时角色数 |
| 群资料 | 改成悬浮窗内的 popover/抽屉：成员、模式、临时角色、绑定工作区、重命名；不再单独开面板 |

## 4. 角色体系

- **持久角色**：存在角色库，跨会话复用；带人格、专长、工具子集、模型档案。
- **临时角色**：只属于一个会话（或一次群聊），关闭会话即销毁；在悬浮窗的成员 popover 里创建。
- **LLM 创建**：主持/单聊里说「需要一个负责 X 的角色」，LLM 可创建角色并加入当前群：
  - 默认先给一张「创建角色」确认卡（名称 / 专长 / 工具 / 是否保存到角色库）；
  - 用户确认后：保存为持久角色，或仅作为本会话临时角色。
- 角色不属于工作区；切换工作区不改变角色库。

## 5. 群组与会话

- 群组 = 名称 + 成员角色 + 协作方式（主持编排 / 圆桌 / 单角色），**没有 workspace_id**。
- 会话 = 群组或单角色的聊天实例；**会话级**可选绑定一个工作区。
- 同一个群的不同会话可以绑定不同工作区，也可以都不绑（纯聊天）。
- 新建会话：选单聊（角色）或群聊（群组）→ 打开悬浮窗；工作区在窗口标题栏里选。
- 群组与工作区的关系只体现在会话标题栏的 chip 上，不存在「群组属于工作区」。

## 6. 与现状的差异（需要改的后端）

| 现状 | 目标 |
| --- | --- |
| `workspaces.kind` / `host_role_id` / `member_role_ids` 参与多角色路由 | 工作区只保留 `root_path` 等文件上下文；多角色只看群组 |
| `agent_teams.workspace_id`（群组属于工作区） | 群组去掉 workspace 归属；会话（`conversations`）增加可选 `workspace_id` 绑定 |
| `roles` 只作为团队成员存在 | 角色独立 CRUD；增加 `scope`（持久/临时）、`source`（user/llm）、`session_id`（临时角色） |
| 团队即群组，成员=角色 | 保留「群组 = 角色集合」，但不再与工作区耦合 |
| 右侧 dock / 会话信息抽屉 | 改成悬浮窗 + 窗内 popover；dock 与顶栏图标移除 |
| 前端单页三栏 | 主壳（rail + 列表 + 画布）+ 悬浮窗层 + dock |

> 这会推翻 P1 里「群组归属工作区」的假设；`agent_teams.workspace_id`、`workspaces.kind` 等列需要迁移/废弃，
> `conversations` 需要新增工作区绑定。属于一次数据模型调整，建议单独一版（3.2.0）。
