交互说明

  1. 1左轨只有四个空间：会话 / 工作区 / 角色 / 群组。设置沉到底部，不再有顶栏一排图标。
  2. 2会话列表只负责「找个对话打开」；聊天本身永远在悬浮窗里，主界面不常驻聊天栏。
  3. 3悬浮窗可多开、拖动、缩放、最小化；点击标题栏置顶，位置与大小按窗口记忆。
  4. 4标题栏的「工作区」chip 是**会话级绑定**：同一个群的两个会话可以绑不同工作区，也可以都不绑。
  5. 5群资料 / 成员 / 临时角色都在悬浮窗自己的菜单里；不再需要单独的「会话信息」抽屉。
  6. 6角色库独立：持久角色跨会话；临时角色只活在一个会话，关闭即销毁；LLM 可在对话中直接创建（默认需一次确认）。
  7. 7群组只是「角色 + 协作方式」，不归属工作区；工作区只出现在会话的绑定 chip 上。
  8. 8工作区画布保留文件树 / 只读预览 / 终端入口，不再承载聊天或角色。
