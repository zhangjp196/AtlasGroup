# Magpie 本机脱敏与模型调用图

> 目标：请求离开这台电脑前，把敏感信息替换成占位符；模型回复与工具参数在
> 本机还原。用量页用一张调用链路图展示「AtlasX → magpie → 模型」的流量与
> 脱敏次数。

## 脱敏口径

模型只会看到 `⟦MG_<类型>_<编号>⟧`，真实值留在本机：

| 类型 | 例子 | 开关 |
| --- | --- | --- |
| 密钥 / Token | `sk-…`、`ghp_…`、`AKIA…`、JWT、`Bearer …`、私钥块、`password=…` | `secrets` |
| 个人信息 | 邮箱、手机号、18 位身份证、IPv4 | `pii` |
| 本机路径 | `/Users/<name>/…`、`/home/<name>/…`、`C:\Users\<name>\…` | `paths` |

- 每次 LLM 调用创建一个内存映射（值 → 占位符），不落库；
- 同一次调用里重复出现的同一个值复用同一个占位符；
- 发给模型的 system / user / assistant / tool 消息与 tool_calls 参数都会脱敏；
- 图片 data URL、附件 URL、消息 id 等不参与脱敏，避免破坏多模态与工具回填。

## 还原点

- 非流式回复：`content` 与 `tool_calls.arguments` 在返回 `LlmResult` 前还原；
- 流式回复：文本 / 思考增量经过 `StreamRestorer`，占位符被切成多个 delta 也能
  拼回；`done` 的正文与 tool_calls 用完整原文再还原一次；
- 工具参数在交给执行器前还原，所以 `read_file` / `shell` 拿到的仍是真实路径；
- 工具结果、记忆、摘要再次发给模型时重新脱敏。

## 设置与 API

设置存在 `app_settings` 的 `magpie` 键，默认开启三类规则：

```json
{"enabled": true, "secrets": true, "pii": true, "paths": true}
```

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/app/magpie` | 设置 / 本次运行统计 / 分类 |
| PUT | `/app/magpie/settings` | 总开关 + 三类规则 |
| POST | `/app/magpie/test` | 脱敏预览（不写入统计） |

统计是进程内累计（`redacted_total` + `by_kind`），重启清零；显示在用量页的
链路图与设置卡片上。

## 边界

正则识别是**尽力而为**：无法保证覆盖所有敏感信息，也不做加密 / 不可逆哈希
（还原需要原文）。它不替代隔离环境；对强隐私要求，仍应关闭联网、限制工作区
或使用独立账号。脱敏失败时按原文发送并写 warning 日志，不阻断对话。
