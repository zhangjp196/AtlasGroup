# Token 用量统计（会话 / 工单 / 任务）

> 目标：把「花了多少 token、生成多快、缓存命中多少」从设置页的全局统计，
> 下钻到每个会话、每张工单、每个后台任务，并保持同一套口径。

## 口径

所有数字都来自 `gdag_nodes` 里 `by=assistant` 的消息 `props.usage`（每轮 run
收尾时落库），不需要额外埋点：

| 字段 | 含义 |
| --- | --- |
| 输入 `prompt_tokens` | 各轮 prompt 之和（多轮工具循环每轮都会重发上下文，累加才是真实开销） |
| 输出 `completion_tokens` | 各轮 completion 之和 |
| 合计 `total_tokens` | 输入 + 输出 |
| 速度 `speed` | 输出 token / LLM 生成耗时（`llm_ms`），单位 t/s |
| 缓存 `cache_rate` | `cached_tokens / prompt_tokens`，命中数来自上游 `prompt_tokens_details.cached_tokens` |
| 上下文 `last_prompt_tokens` | 最近一轮真实 prompt（= 当前上下文占用），压缩后会回落 |
| 轮次 `rounds` / 回复数 `turns` | 实际 LLM 往返次数 / 有 usage 的助手消息条数 |

实体归属：

- **会话**：只算前台对话（`stage=exploration`），与既有 `conversation.usage_total`
  一致；后台任务成员的 token 不重复算进会话。
- **任务（群组后台任务）**：按成员 run 的 `props.run_id` 精确聚合，任务用量 =
  各成员 run 之和。
- **工单**：
  - 后台任务自动建的工单（`meta.managed_by=team_task`）按 `meta.task_id` 汇总成员
    run，不会把同一会话里其它任务的 token 算进来；
  - 手动 / 来源工单按它独占的会话聚合（每次派活都会新建一个会话）。

## 后端

- `services/agent_zero/services/usage_service.py`
  - `usage_by_conversation(ids, stage=...)` / `usage_by_run(ids)`：批量聚合，避免 N+1；
  - `task_run_map(ids)` / `usage_by_task(ids)`：任务 → 成员 run → 用量；
  - `empty_usage()` / `sum_usage()`：统一派生字段（缓存率 / 速度 / 均值）。
- `conversation.list_conversations`：每条会话附 `usage`（整页一次查询）。
- `conversation.usage_total`：补 `total_tokens` / `avg_tokens_per_turn`，
  会话详情同时返回 `usage` 与旧字段 `usage_total`。
- 新增 `GET /conversations/{id}/usage`：轻量用量接口（不返回转录），
  供会话管理抽屉 / 聊天头部使用。
- `work_service.list_items` / `get_item`：工单附 `usage`；`stats` 增加
  `tokens / prompt_tokens / completion_tokens / cached_tokens / llm_ms`。
- `team_task_service.list_tasks` / `get_task`：任务附 `usage`，成员附各自的 `usage`
  （列表接口一次聚合整页 run）。

## 前端

- `api/types.ts`：新增 `TokenUsage`；`Conversation` / `Message` / `WorkItem` /
  `TeamTask` / `TeamTaskMember` / `RunEvent` 增加 usage 字段。
- `lib/usage.ts`：把后端字段归一成展示口径，并把「已落库」与「运行中实时快照」
  相加（`mergeUsage`）。
- `components/TokenMeter.vue`：
  - `tile`：卡片里的 4 列指标条（输入 / 输出 / 速度 / 缓存 + 底部缓存进度），
    没有用量时整条隐藏；
  - `inline`：任务浮窗等窄行里的文字版（入 / 出 / 速度 / 缓存）；
  - `hero`：工单页头部汇总（大号合计 + 缓存环 + 速度），也可用于执行画布；
  - `panel`：抽屉 / 弹层里的完整面板（缓存环 + 输入 / 输出 / 速度 / 轮次 + 缓存条 + 上下文）。
- 视觉：缓存环用 `conic-gradient`，缓存率分级着色（≥50% 绿、≥20% 黄、其余红）；
  卡片指标条带轻渐变与缓存进度条，浅色 / 深色主题共用同一套 token（`--panel/-line/-accent`）。
- 展示位置：
  - 会话列表卡片（4 列指标条）+ 筛选栏合计胶囊；
  - 聊天头部用量胶囊（缓存环 + 合计 + 速度 + 缓存率），点开是完整面板，
    面板里可「打开会话管理」；
  - 会话管理抽屉「Token 用量」；
  - 工单列表卡片、工单详情抽屉，以及工单页头部右侧的 hero 汇总卡
    （合计 / 入 / 出 / 轮次 / 缓存环 / 速度）；
  - 任务浮窗：状态与用量合并成一行 meta，分组标题显示合计；
  - 执行画布：任务卡片、任务详情（hero）、成员列表显示任务 / 成员用量；
  - 助手消息的时间线 meta 旁显示该轮 `↑输入 ↓输出`。
- 布局调整：
  - 工单页统计卡恢复 4 列（≤980px 两列），token 汇总移入 hero 右侧，填补原空白；
  - hero 在 ≤960px 自动换行，用量卡占满整行；
  - 会话卡片用量条固定 4 列，窄卡片仍可读；
  - 聊天头部用量胶囊在 ≤860px 隐藏，避免挤掉操作按钮。
